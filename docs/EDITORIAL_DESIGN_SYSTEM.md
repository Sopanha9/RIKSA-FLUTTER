# Riksa Editorial Learning System

Riksa uses the composition and restraint of an editorial learning product while
keeping its own Cambodian identity. Screens should feel related before any logo
or product name is visible.

## Visual hierarchy

- Give every screen one dominant heading, one primary action, and one focal
  surface.
- Use near-black or aubergine for interaction anchors. Pink is an accent, not a
  default border.
- Prefer neutral canvas plus white surfaces. Use one pastel family for a feature
  region instead of mixing all subject colors on one screen.
- Remove containers that exist only to group other containers. Space is the
  default separator; borders are the exception.

## Surface grammar

- Large feature panels: 28px radius.
- Content cards: 20px radius.
- Compact controls: 14px radius or a full pill.
- Search and input fields use the quiet field surface without an idle border.
- Primary actions use the near-black editorial anchor in light mode and pink in
  dark mode.

## Typography

- Display and screen headings may use 700–800 weight.
- Card titles use 700–800 only when they are the card's primary content.
- Metadata, labels, and supporting copy should stay between 400–600 so the
  hierarchy does not flatten.
- Khmer titles use Koulen; Khmer body copy uses Kantumruy Pro with Noto Sans
  Khmer as the fallback.

## Illustration and iconography

- Editorial illustrations belong to entry points, empty states, milestones, and
  major learning moments. They should shape the composition, not sit as a small
  decoration inside a generic card.
- Favor simple monochrome line icons. Avoid ornamental rings, repeated symbols,
  and large icons that do not communicate state or content.
- Future character artwork should depict Cambodian learners and familiar local
  education settings while retaining the black-line and soft-pastel language.

## Content types

- Lessons use a quiet subject-colored feature panel.
- Challenges use an inverted near-black panel with a pink achievement accent.
- Roadmaps use a mint panel and route iconography.
- Type should change the card's structure or dominant surface; do not rely on a
  tiny chip alone.
